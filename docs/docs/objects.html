6.1 Animal Objects

Three types of animal object are provided in PyPedal (Section 6.1.1). Users will typically work with instances of NewAnimal objects, while LightAnimal (?sec-objects-animal-objects-light-animal) and SimAnimal (?sec-objects-animal-objects-sim-animal) objects are of interest primarily to developers. Detailed descriptions of each class and its methods may be found in the API Reference for the pyp_newclasses module (?sec-functions-pyp-newclasses).

6.1.1 The NewAnimal Class

NewAnimal objects have the seven methods listed in ?tbl-objects-animal-objects-new-animal-methods. The methods focus on returning information about an instance of an object; calculations are left to functions in, e.g., the pyp_metrics pyp_nrm modules.

## Animal Objects {#sec-objects-animal-objects}

Three types of animal object are provided in PyPedal (@sec-objects-animal-objects-new-animal). Users will typically work
with instances of `NewAnimal` objects, while `LightAnimal` (@sec-objects-animal-objects-light-animal) and `SimAnimal`
(@sec-objects-animal-objects-sim-animal) objects are of interest primarily to developers. Detailed descriptions of each
class and its methods may be found in the API Reference for the `pyp_newclasses` module (@sec-functions-pyp-newclasses).
